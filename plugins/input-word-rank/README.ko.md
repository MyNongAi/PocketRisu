# 입력 단어 순위 (RisuAI 플러그인)

내가 보낸 메시지에서 자주 쓴 **단어**, **표현**(2~4단어 묶음), **문장**의 순위를 매기는 플러그인입니다. 플러그인 API 3.0만 씁니다. 순정 RisuAI와 PocketRisu에서 다 돌아갑니다.

## 하는 일

고른 범위의 채팅에서 내 메시지(유저 메시지)만 읽어 셉니다. 봇의 답은 세지 않습니다. 채팅은 읽기만 하고 아무것도 고치지 않습니다.

| 탭 | 세는 것 |
|---|---|
| 단어 | 띄어쓰기로 나눈 말. 앞뒤 문장부호는 뗍니다. 글자 없이 숫자와 기호만 있는 말은 뺍니다. |
| 표현 | 한 문장 안에서 이어 쓴 2~4단어 묶음. 두 번 이상 쓴 것만 보입니다. 더 긴 표현 안에 늘 같이 나오는 짧은 표현은 긴 쪽만 보입니다. |
| 문장 | 똑같이 쓴 문장. 문장부호와 대소문자는 무시하고 비교합니다. 두 번 이상 쓴 것만 보입니다. |

세기 전에 메시지에서 아래 것들을 뺍니다.

- `{{...}}` 매크로, HTML 태그, 주소(URL), `*` `_` `~` 같은 마크다운 기호.
- 봇이나 모듈이 입력에 넣는 표식. 띄어쓰기 없이 영문·숫자·기호만 든 대괄호(`[SCENE_START]`, `[ACT:card_1]`, `[1-2]`)와 JSON(`{"hp":3}`)이 해당합니다.
- 글자 없이 숫자와 기호만 있는 말(`12`, `1-2`, `3:00`).

`ㅋㅋㅋㅋㅋ`처럼 같은 자음·모음이 길게 이어진 것은 세 글자로 줄여서 하나로 셉니다.

**복사한 채팅은 한 번만 셉니다.** 채팅을 복사하거나 분기하면 앞부분 메시지가 복사본에도 그대로 들어갑니다. 보낸 시각(시각이 없으면 메시지 ID)과 글이 같은 메시지를 다른 채팅에서 다시 만나면 세지 않습니다. 한 채팅 안에서 같은 말을 또 쓴 것은 그대로 셉니다. 복사한 뒤 고친 메시지는 글이 달라져서 따로 셉니다. 결과 줄에 겹쳐서 뺀 입력 수가 나옵니다.

## 설치

설정 → 플러그인 → **플러그인 임포트**에서 `input-word-rank.js`를 고릅니다. 따로 허락을 묻는 권한은 없습니다.

## 사용

설정 메뉴에서 **📊 입력 단어 순위**를 엽니다.

- **범위:** 지금 채팅 / 지금 봇의 모든 채팅 / 모든 봇. "지금"은 마지막으로 연 봇과 채팅입니다.
- **조사 떼기 (대략):** "사람이/사람을/사람에게"를 "사람"으로 모읍니다. 사전 없이 끝말만 보고 떼므로 틀릴 때가 있습니다. 표현과 문장은 쓴 그대로 셉니다.
  - 떼고 남는 말이 한 글자면 떼지 않습니다(작은, 마을, 앞으로). 대명사는 예외로 뗍니다(나는 → 나, 내가 → 내, 너를 → 너).
  - 앞 글자의 받침에 맞는 조사만 뗍니다. 이·은·을·과는 받침 뒤(사람이), 가·는·를·와는 받침 없는 글자 뒤(친구가)에서만 뗍니다. 그래서 "누군가"는 그대로 둡니다.
  - "하지만, 그래도, 그대로, 고양이" 같은 말은 그대로 둡니다.
- **괄호 속 빼기 (OOC):** `( )`, `（ ）`, `[ ]` 안의 글을 빼고 셉니다.
- **영어 빼기:** 영문자가 든 단어(`ai가` 포함)를 세지 않습니다. 표현은 그 단어를 건너 이어지지 않습니다. 문장은 영문자가 한글보다 많을 때만 통째로 뺍니다. "응 알았어 OK"처럼 한국어 문장에 영어가 조금 섞인 것은 문장 탭에 남습니다.
- **빼고 셀 단어:** 쉼표나 띄어쓰기로 나눠 적습니다. 단어 탭에서만 뺍니다.

**세기**를 누르면 진행 상황(봇, 채팅, 입력 수)이 보이고, **멈추기**를 누르면 그때까지 센 것으로 순위를 보여 줍니다. 각 탭은 위에서 100개까지 보입니다. **텍스트로 보기**를 누르면 순위를 글로 펼쳐서 복사할 수 있습니다.

고른 옵션은 이 기기에만 저장됩니다(`getLocalPluginStorage`). 센 결과는 저장하지 않습니다.

## 한계

- **PocketRisu의 비활성 봇은 세지 못합니다.** 비활성 봇은 플러그인이 보는 봇 목록에 없습니다. 세고 싶으면 그 봇을 다시 활성화하세요. 순정 RisuAI에는 비활성 기능이 없어서 모든 봇을 셉니다.
- PocketRisu는 아직 열지 않은 채팅을 서버에서 하나씩 받아 옵니다. 채팅이 많으면 "모든 봇"은 몇 분 걸릴 수 있고, 폰에서는 데이터도 씁니다. 받아 온 채팅은 세는 데만 쓰고 앱에 올리지 않습니다. 받지 못한 채팅은 "못 읽은 채팅 N개"로 따로 알려 줍니다.
- 기록이 아주 많아 표가 너무 커지면(종류별 40만 개 넘게), 한 번만 나온 말을 버리면서 셉니다. 그러면 결과 줄에 "대략"이라고 나옵니다. 위쪽 순위는 거의 그대로입니다.
- 글자 사이를 띄어 쓰지 않는 말(붙여 쓴 문장)은 한 단어로 셉니다.
- **봇이 고쳐 쓴 입력은 고친 대로 셉니다.** 봇의 입력 수정 정규식(editinput)이나 Lua(`listenEdit('editInput', …)`)가 보낼 때 입력에 글을 붙이면, 앱에는 붙은 뒤의 글만 저장됩니다. 그래서 내가 친 부분만 골라낼 수 없습니다. 붙는 글이 영어이거나 표식이면 **영어 빼기**로, 대괄호 안이면 **괄호 속 빼기**로 대부분 빠집니다.
