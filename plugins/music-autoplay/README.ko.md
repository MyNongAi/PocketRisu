# 음악 자동 재생 (RisuAI 플러그인)

봇의 답변에 곡이 나오면 그 곡을 찾아 재생하는 플러그인입니다. 플러그인 API 3.0만 씁니다.

## 하는 일

답변 안의 곡 표시 `<music>아티스트 - 제목</music>`를 메시지 속 카드로 바꾸고, 고른 플랫폼에서 재생합니다.

| 플랫폼 | 동작 |
|---|---|
| 유튜브 | 유튜브 검색 API로 곡을 찾아 메시지 안에 유튜브 플레이어를 넣습니다. 공식 음원(아티스트 "- Topic" 채널, 음악 카테고리)을 먼저 고르므로 유튜브 뮤직과 같은 음원이 나옵니다. **방금 받은 답변의 곡만 바로 재생**되고, 그 전에 나오던 곡의 플레이어는 내려가서 두 곡이 겹치지 않습니다. 예전 메시지의 카드와 앱을 다시 연 뒤의 카드는 눌러야 재생됩니다. |
| 스포티파이 | 답변이 끝나면 폰이나 PC에 켜 둔 스포티파이 앱에서 곡을 재생합니다(Spotify Connect). 화면이 꺼져도 계속 나옵니다. **스포티파이 프리미엄이 필요합니다.** |
| 멜론 링크 | 멜론 검색 링크만 보여 줍니다. 멜론은 공개 API가 없습니다. |
| 끄기 | 곡 표시를 곡 이름 한 줄로만 보여 줍니다. |

봇이 곡 표시를 쓰도록, 플러그인이 요청마다 짧은 지시문을 덧붙입니다("곡 표시 지시문"에서 끌 수 있습니다). 끄면 봇 설명이나 로어북에 직접 같은 규칙을 적어 주세요.

한 번 찾은 곡은 플러그인 저장소(`pluginStorage`)에 기억해서 다시 검색하지 않습니다.

## 설치

1. 설정 → 플러그인 → **플러그인 임포트**에서 `music-autoplay.js`를 고릅니다.
2. 설정 → 플러그인에서 **재생 플랫폼**을 고릅니다.
3. 처음 답변을 받을 때 "채팅 내용을 교체할 권한" 창이 뜨면 **예**를 누릅니다. 지시문을 덧붙이고 새 답변을 알아보는 데 씁니다. 이전 곡을 멈출 때 "메인 Document 접근" 창도 한 번 뜹니다.

### 유튜브 API 키 만들기

1. Google Cloud Console(console.cloud.google.com)에서 프로젝트를 만듭니다.
2. "API 및 서비스 → 라이브러리"에서 **YouTube Data API v3**를 사용 설정합니다.
3. "사용자 인증 정보 → API 키 만들기"로 키를 만들어 플러그인 설정의 **유튜브 API 키**에 넣습니다.

무료 할당량은 하루 10,000단위이고, 검색 한 번에 100단위라 하루 약 100곡까지 새로 찾을 수 있습니다. 이미 찾은 곡은 할당량을 쓰지 않습니다. 키가 없으면 카드에 "유튜브 뮤직에서 찾기" 링크만 보입니다.

### 스포티파이 연결

1. 스포티파이 개발자 사이트(developer.spotify.com)의 Dashboard에서 앱을 만듭니다.
   - Redirect URI: `http://127.0.0.1:8888/callback`
   - API: Web API
2. 받은 **Client ID**를 플러그인 설정에 넣습니다.
3. 설정 메뉴의 **🎵 음악 자동 재생**을 엽니다.
   - "로그인 주소 만들기"를 누릅니다.
   - 나온 주소를 새 탭에서 열어 로그인합니다.
   - 넘어간 페이지는 열리지 않는 게 정상입니다. 그 주소 전체를 복사해 붙여 넣고 **연결**을 누릅니다.
4. 스포티파이 앱을 켜 둔 채 **시험 재생**으로 확인합니다.

스포티파이 로그인 정보는 그 기기에만 저장됩니다(세이브 파일에 들어가지 않음). 그래서 기기마다 한 번씩 연결합니다.

## 한계

- 유튜브 바로 재생은 브라우저의 자동 재생 규칙을 따릅니다. 데스크톱과 안드로이드 크롬에서는 메시지를 보낸 직후라 대개 재생되지만, 아이폰 사파리는 막을 수 있습니다. 그때는 카드를 눌러 재생합니다.
- 유튜브 플레이어는 폰 화면이 꺼지거나 다른 앱으로 가면 멈춥니다. 스포티파이 방식은 계속 나옵니다.
- 플러그인은 보안 규칙상 화면에 떠 있는 플레이어를 만들 수 없어서, 플레이어는 메시지 안에 있습니다.
- 유튜브 뮤직 앱 자체를 조종하는 방법은 없습니다(공식 API 없음).
- 검색이 틀린 곡을 고를 수 있습니다. 봇이 원어 제목과 아티스트를 쓸수록 정확합니다.
