# 떠 있는 버튼 숨기기 (RisuAI 플러그인)

봇이 화면에 띄워 두는 작은 버튼 묶음(상태창, 지도, 메뉴를 여는 고정 버튼 등)을 **봇마다** 숨기는 플러그인입니다. 플러그인 API 3.0만 씁니다.

## 하는 일

스위치를 켠 봇에서, 메시지 본문과 배경(배경 HTML) 안의 요소 중 아래 셋을 모두 만족하는 것만 숨깁니다.

- 화면에 고정되어 있음 (봇 CSS의 `position: fixed` 규칙, 또는 인라인 `style`)
- 화면 넓이의 20% 이하
- 버튼, 라벨, 트리거이거나 그것을 담고 있음

메시지 글 속의 버튼(고정이 아님)과 열려 있는 큰 팝업(20% 초과)은 그대로 보입니다. 스위치를 끄면 바로 다시 보입니다.

## 설치

1. 설정 → 플러그인 → **플러그인 임포트**에서 `hide-floating-buttons.js`를 고릅니다.
2. "메인 Document에 접근하려고 합니다" 창이 뜨면 **예**를 누릅니다. 처음 한 번만 묻습니다.

## 사용

채팅 입력창 왼쪽 메뉴(☰)에서 **떠 있는 버튼 숨기기: 끔/켬**을 누릅니다. 지금 보고 있는 봇에만 적용됩니다.

설정은 플러그인 저장소(`pluginStorage`)에 `hide_floating_buttons:<봇 ID>`로 저장됩니다. 세이브 파일에 같이 들어가므로 새로고침해도, 같은 세이브를 쓰는 다른 기기에서도 유지됩니다.

플러그인은 네트워크 요청을 하지 않습니다. 캐릭터 정보에서는 봇 ID(`chaId`)만 씁니다. 화면에는 숨김 표시용 `x-` 속성과 스타일 규칙 하나만 더합니다.

## 한계

- 플러그인은 계산된 스타일(`getComputedStyle`)을 읽을 수 없습니다. 그래서 봇 `<style>`의 규칙과 인라인 스타일만 보고 "고정"을 판단합니다.
  - 더 구체적인 다른 규칙이 `position`을 덮어써도 고정으로 봅니다. (인라인 스타일로 덮어쓴 것은 압니다.)
  - `@media` 조건은 px 단위 너비/높이와 `print`만 읽습니다. 그 밖의 조건(`pointer`, `em` 단위 등)은 맞는 것으로 봅니다.
  - `visibility: hidden`이나 투명도로만 가려진 요소는 구분하지 못합니다. (`display: none`처럼 크기가 0인 것은 건너뜁니다.)
- 창 크기 변경 이벤트를 받을 수 없어, 화면을 돌리거나 창 크기를 바꾸면 다음 화면 변화(클릭 등) 때 다시 판단합니다.
- 한 번 숨긴 요소는 스위치를 끄거나 화면 크기가 바뀔 때까지 숨긴 채로 둡니다. (숨긴 요소는 크기를 잴 수 없기 때문입니다.)
- 메시지가 다시 그려지면(답변 생성 중 등) 버튼이 1초 안쪽으로 잠깐 보였다가 다시 숨겨질 수 있습니다.
- 배경 레이어는 PocketRisu/RisuAI 화면 구조(클래스 이름)로 찾습니다. 앱 구조가 바뀌면 배경 쪽 버튼은 못 찾을 수 있습니다. 메시지 쪽은 `.chattext` 기준이라 영향이 적습니다.
- 메인 Document 접근을 거절하면 아무것도 하지 않습니다. 다시 허용하려면 설정 → 플러그인에서 이 플러그인의 권한을 초기화합니다.
- 플러그인을 끄거나 지우면 숨겼던 버튼이 다시 보입니다.

PocketRisu v1.15.1에서 폰 너비(380px)와 데스크톱 너비로 시험했습니다.
