# PocketRisu 병합용 컬렉션 내보내기

로컬 Risu와 모바일·PC 웹 Risu에서 봇, 모듈, 페르소나를 각각 내보내는 Risu API v3 플러그인입니다.

## 사용 순서

1. PocketRisu의 `설정 → 마이그레이션 → 내보내기 플러그인 받기`로 플러그인을 내려받습니다.
2. 원본 Risu의 `설정 → 플러그인`에서 `pocketrisu-source-collection-exporter.js`를 가져옵니다.
3. 플러그인에 데이터베이스 접근 권한을 허용합니다.
4. 설정 왼쪽의 `PocketRisu 병합용 백업`을 엽니다.
5. `로컬리스`, `모바일웹리스`, `PC웹리스`처럼 출처 이름을 입력합니다.
6. 봇·모듈·페르소나를 각각 내보냅니다.
7. 여러 `part` 파일이 생성되면 빠짐없이 한 폴더에 보관합니다.
8. PocketRisu의 `설정 → 마이그레이션 → 출처별 컬렉션 병합`에서 part 파일을 모두 선택합니다.

채팅과 플러그인은 포함하지 않습니다. 동일한 이름의 항목도 삭제하거나 자동 병합하지 않으며, PocketRisu에서 새 ID를 부여하여 출처별로 보존합니다. 출처 이름별 관계 ID는 기기 로컬 저장소에 보관하므로 봇과 모듈을 다른 날 내보내도 다시 연결할 수 있습니다. 저장이 불가능한 환경에서는 화면에 경고가 나오며, 그때만 같은 플러그인 화면을 닫기 전에 두 종류를 모두 내보내야 합니다.

일반 `assets/...` 파일은 SHA-256과 크기를 함께 기록합니다. 16MB를 넘는 단일 에셋은 모바일 메모리를 보호하기 위해 바이너리만 제외하되, 경로·크기·사유를 각 part의 `omittedAssets` 목록에 남겨 나머지 봇이나 모듈까지 잃지 않게 합니다. 내보내기가 중단된 묶음에는 마지막 표시가 없어 PocketRisu가 가져오기를 거부합니다.

모바일 브라우저의 메모리와 다중 다운로드 제한 때문에 기본 조각 크기는 12MB입니다. 브라우저에서 여러 파일 다운로드 권한을 묻는다면 허용해야 합니다.
