# 📁 장면 접기 (RisuAI 모듈)

끝난 **배틀**, **NSFW** 장면, 또는 직접 정한 장면을 모델에게 보내는 요청에서 접고, 그 자리에 짧은 요약을 넣는 모듈입니다. 재미는 그대로 보고, 결과만 다음 이야기에 남깁니다.

채팅 원문은 지우지 않습니다. 접힌 장면은 화면에 요약 카드로 보이고, 카드에서 언제든 펼쳐 볼 수 있습니다.

## 설치

1. 설정 → 모듈 → **임포트**에서 `dist/scene-fold-0.1.0.risum`을 고릅니다.
2. "이 모듈은 저수준 접근을 사용합니다" 창이 뜨면 **허용**을 누릅니다. 보조 모델에게 판단과 요약을 맡기려면 꼭 필요합니다. 허용하지 않으면 모듈이 들어오지 않습니다.
3. 쓰고 싶은 봇이나 채팅에서 모듈을 켭니다(전역으로 켜도 됩니다).
4. 보조 모델을 정해 두세요(설정 → 기타 봇 / 모델 바인딩의 보조 모델). 판단과 요약은 싼 모델로 충분합니다.

## 하는 일

1. **장면 찾기**: 답이 올 때마다 그 답에서 장면이 시작하거나 끝나는지 정합니다.
   - **보조 모델이 판단**(기본): 최근 메시지 몇 개를 보조 모델에게 보내 "시작 / 끝 / 둘 다 / 없음"을 묻습니다. 답마다 보조 모델을 한 번 부릅니다.
   - **메인 모델이 표시**: 요청 끝에 짧은 지시를 붙여, 메인 모델이 장면 앞뒤에 `[[SCENE START: battle]]`, `[[SCENE END]]`를 쓰게 합니다. 이 표시는 답이 오면 바로 숨김 표시로 바뀌어 화면에도, 다음 요청에도 보이지 않습니다. 장면이 답 12개 넘게 안 끝나면 보조 모델에게 한 번 확인합니다.
2. **접기**: 장면이 끝나고 정한 만큼 답이 더 오면(기본 2개) 보조 모델(또는 메인 모델)이 그 장면을 요약합니다. 그 뒤로는 요청에서 그 장면의 메시지가 빠지고, 그 자리에 요약 한 덩어리가 들어갑니다.
3. **화면**: 장면 첫 메시지 자리에 요약 카드가 보이고, 나머지 메시지는 한 줄로 줄어듭니다. 카드의 **펼치기**로 원문을 볼 수 있습니다(화면에서만 펼쳐지고, 요청은 그대로 접혀 있습니다).

장면의 시작과 끝은 메시지 안의 보이지 않는 표시(`<!--sf:...-->`)로 기록됩니다. 그래서 리롤하거나 메시지를 지워도 범위가 어긋나지 않습니다. 끝 표시가 있던 답을 리롤하면 그 장면은 다시 열린 상태가 됩니다. 메시지 편집 칸에 이 표시가 보이면 지우지 마세요.

## 토글 (모듈 토글 메뉴)

| 토글 | 기본 | 설명 |
|---|---|---|
| ⚔️ 배틀 | 켬 | 시작과 결과가 있는 모든 겨루기: 전투·결투(포켓몬 배틀 포함), 던전·게이트·레이드·탐험, 수련·대련, 미니게임, 보드·카드 게임, 포커·도박 |
| 🔞 NSFW | 끔 | 성적인 장면. 요약에는 관계 변화와 약속처럼 뒤에 남을 것만 적고 노골적인 묘사는 빼라고 지시합니다 |
| ✏️ 사용자 정의 | 끔 | 아래 두 칸에 적은 대로 |
| └ 사용자 정의 이름 | | 카드와 요약에 쓰는 이름 |
| └ 언제 시작하고 끝나는지, 무엇을 남길지 | | 예: "마을 밖으로 나가 사냥을 시작할 때부터 마을로 돌아올 때까지. 잡은 것, 번 돈, 다친 것을 남김." 이 칸이 비어 있으면 사용자 정의는 꺼진 것으로 봅니다 |
| 장면 찾기 | 보조 모델이 판단 | 위 설명 참고 |
| 끝난 뒤 접기까지 | 답 2개 | 끝난 직후의 여운과 대화는 원문으로 보게 하는 유예입니다. 바로·1·2·3·4·6개 |
| 요약 쓰는 모델 | 보조 모델 | 메인 모델로 바꿀 수 있습니다 |
| 메시지 아래 장면 버튼 | 보이기 | 손으로 접기 위한 버튼 줄 |
| ✂️ 원문 잘라내기 (비권장) | 끔 | 아래 "원문 잘라내기" 참고 |

각 장면 종류는 따로 켜고 끕니다. 리스의 토글은 처음에 빈 값이라, 기본이 "켬"인 배틀이 체크칸이면 꺼진 것처럼 보이게 됩니다. 그래서 종류마다 "켬/끔" 선택 칸으로 두었습니다.

## 손으로 접기

메시지 아래의 작은 버튼 줄로 직접 정할 수 있습니다.

- **▶ 여기부터 장면**: 이 메시지에서 장면을 시작합니다. 종류를 고르는 창이 뜹니다.
- **■ 여기까지 장면**: 열린 장면을 이 메시지에서 끝냅니다.
- 요약 카드의 **다시 요약**: 요약을 새로 만듭니다.
- 요약 카드의 **접기 해제**: 그 장면의 표시를 모두 지워, 원래 메시지로 돌아갑니다.

자동 판단이 놓친 장면이나, 이미 지나간 장면도 이렇게 접을 수 있습니다. 끝을 정한 시점에 이미 유예만큼 답이 지났으면 바로 요약하고 접습니다.

## 장기 기억(하이파)과의 관계

접기는 **모델에게 보내는 요청만** 바꿉니다. 채팅 원문은 그대로라서 하이파 같은 장기 기억은 원문을 보고 평소처럼 요약합니다. 하이파가 요약만 보게 하려면 아래의 "원문 잘라내기"를 켜야 합니다(비권장).

같은 장면이 두 번 요약되어 둘 다 요청에 들어가는 일은 없습니다. 접기 요약은 그 장면의 메시지가 아직 요청에 들어갈 때만 그 자리를 대신합니다. 장기 기억이 그 구간을 이미 기억으로 넘겨 요청에서 빠졌다면, 접기 요약도 넣지 않습니다.

## 원문 잘라내기 (비권장, 기본 끔)

리스에 들어 있는 장기 기억(하이파)은 채팅 메시지를 전부 읽습니다. 모듈은 하이파가 접힌 구간을 건너뛰게 할 수 없어서, 기본 방식에서는 하이파가 배틀 원문까지 요약합니다. 하이파가 **요약만** 보게 하고 싶을 때 이 토글을 켭니다.

- 켜면 장면이 접히는 순간(요약이 만들어진 뒤) 그 장면의 메시지들을 채팅에서 지우고, 그 자리에 요약 메시지 하나를 넣습니다(FOLD 1.0과 같은 방식).
- 지운 원문은 채팅 상태에 보관하고, 요약 메시지의 **되돌리기**로 원래 자리에 돌려놓을 수 있습니다. 돌려놓은 장면은 다시 잘리지 않고, 기본 방식처럼 요청에서만 접힙니다.
- 원문 글자 수가 모두 합쳐 30만 자를 넘는 장면은 보관이 부담스러워서 자르지 않고 기본 방식으로만 접습니다.
- 그래서 비권장입니다.
  - 돌려놓은 메시지는 글만 돌아옵니다. 그 메시지의 다른 리롤 답(스와이프)과 메시지 ID 같은 정보는 돌아오지 않습니다.
  - 요약 메시지를 지우면 보관한 원문도 되돌릴 길이 없어집니다.
  - 잘라낸 뒤 그 앞뒤로 리롤·삭제를 해도 잘린 원문은 평소처럼 되살릴 수 없습니다.
  - 하이파가 이미 그 구간을 요약한 뒤에 자르면, 하이파 쪽 기록과 채팅이 어긋날 수 있습니다(보통은 장면이 막 끝난 최근 구간이라 아직 요약 전입니다).

## 한계

- 보조 모델 판단은 답마다 보조 모델을 한 번 부릅니다. 싼 모델을 권합니다. 가끔 잘못 판단하면 버튼으로 고치세요.
- 메인 모델 표시 방식은 모델이 표시를 빼먹거나 엉뚱한 곳에 쓸 수 있습니다.
- 다른 모듈이나 정규식이 메시지 끝의 `<!--sf:...-->` 표시를 지우면 그 장면은 인식되지 않습니다.
- 번역, 로그 복사처럼 원문 그대로를 쓰는 기능에는 표시가 섞일 수 있습니다(HTML 주석이라 대부분 보이지 않습니다).
- 저수준 접근이 꺼져 있으면 판단과 요약을 못 해서 장면이 접히지 않습니다.

## 만든 곳과 고마운 분들

- PocketRisu 개인 포크에서 만들었습니다. 소스: `modules/scene-fold/scene-fold.lua`, 빌드: `node modules/scene-fold/build.mjs`.
- 아이디어는 아카라이브 AI 채팅 채널의 두 모듈에서 얻었습니다. 코드는 가져오지 않고 새로 짰습니다.
  - **FOLD 모듈** (오리오리오리오리): 모델이 장면 앞뒤에 표시를 남기고, 장면이 끝난 뒤 유예를 두고 요약하는 아이디어.
  - **컨텍스트 폴드** (트러플소금): 원문은 두고 요청에서만 빼는 방식과 메시지 아래 버튼 줄.
